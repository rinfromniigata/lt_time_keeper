S03f終了の確認

「終了」ボタンか Esc キーで出す。表示中も計測は止めない。v0.2.0 で次の2点を変えた。(1) 最初のフォーカスを「終了する」に置く（v2 スペックシートの「モックとの差分」を取り込み）。Enter で終了、Esc で続ける。確認中の Space は何もしない。(2)「今後この確認を表示しない」を追加した。チェックを入れて「終了する」を押したときだけ記録し、「続ける」では記録しない。元に戻すのは環境設定（S05）から。確認を出さない設定のときは、「終了」ボタンも Esc キーも、すぐに S01 へ戻る。

アプリ情報

プライバシーポリシー

LTタイムキーパーが扱う情報と、使う端末の機能についての説明です。

集める情報

このアプリは、あなたの個人情報や利用状況を集めません。アカウント登録、解析ツール、広告、Cookie による追跡はありません。

端末に保存する情報

環境設定の値（言語・表示テーマ・音量・振動・終了の確認）を、この端末のブラウザの中にだけ保存します。持ち時間・ベル・表示名は保存しません。保存した値は、ブラウザでこのサイトのデータを消すと消えます。

通信なしで動かすために、アプリ本体のファイルもブラウザに保存します。

外部への送信

入力した内容や保存した値を、外部へ送ることはありません。通信するのは、アプリ本体と更新を lt.rinontech.com から読み込むときだけです。この配信は Cloudflare Pages が行います。

使う端末の機能

どれも許可を求めるダイアログは出ません。

使うもの
  • 画面のスリープ防止（計測中だけ）
  • 音の再生（ベル）
  • 振動（対応した端末で、オンにしたときだけ）
  • 全画面表示（ボタンか F キーを押したときだけ）
使わないもの

カメラ、マイク、位置情報、通知、連絡先・写真・ファイル

このポリシーの変更

内容を変えるときは、アプリの更新と一緒にお知らせします。このポリシーはバージョン 0.2.0 時点のものです。

決まったこと（v0.2.0）

  • 色は、ライト・ダークとも WCAG 2.2 AA を満たす（参考：色のコントラスト）。状態色は図形用と文字用（-text）に分け、入力欄などの境界は --color-border-input で描く
  • v0.2.0 から日本語・英語・中国語（簡体字 zh-Hans）に対応する。原文は日本語。文言はすべて辞書から引く
  • アプリ名は、日本語「LTタイムキーパー」、英語「LT Timekeeper」、中国語「LT 计时器」
  • 言語の初期値はブラウザの言語に合わせる。ja・en・zh 以外は英語にする（S05）
  • 書体は言語ごとに切り替える（--font-sans-ja / -en / -zh-hans）。外部フォントは使わない
  • 環境設定を新しく作り、タブで「一般・音・アプリ情報」の3つに分ける（S05〜S05c）。S01 のヘッダーの歯車から開き、計測中には開けない
  • ヘッダーのボタンは歯車だけにする。テーマのメニュー（v2 の S01e）とヘッダーの GitHub リンクはなくし、ソースコードへのリンクは S05b に置く
  • 音の設定（音量・試し鳴らし・振動）は S01 から環境設定へ移す（S05a）
  • 環境設定の値（言語・表示テーマ・音量・振動・終了の確認）は端末に保存する。持ち時間・ベル・表示名は保存しない
  • 終了の確認に「今後この確認を表示しない」を付ける。最初のフォーカスは「終了する」（S03f）
  • 確認を出さない設定のときは、「終了」ボタンも Esc キーもすぐに終了する
  • ライセンスは Apache License 2.0（v0.1.0 から変えない）。使用しているオープンソースソフトウェアの一覧も S05b に出す
  • アプリ情報からプライバシーポリシーを開ける（S05c）。日英中で載せる
  • オープンソースソフトウェアの一覧はビルド時に自動で作る（S05b）
  • README は日英中の3つを用意する。そのほかのリポジトリ文書は日本語だけで書く
